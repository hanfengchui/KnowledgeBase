# KnowledgeHub AI 产品与服务说明

## 生效范围

适用于 KnowledgeHub AI 标准版、专业版和私有化部署项目的售前、交付与运营沟通。

## 适用对象

产品经理、售前顾问、客户成功经理、实施顾问、运营支持人员。

## 正文条款

### 1. 产品定位

KnowledgeHub AI 是面向企业内部知识管理与业务辅助查询的统一平台，核心目标是把分散在文档、制度、FAQ 和结构化业务系统中的信息组织到同一问答入口中。

### 2. 核心模块

平台当前提供以下核心模块：

1. 多知识库管理：支持为不同部门、产品线或业务场景创建独立知识库。
2. 文档中心：支持 TXT、Markdown、PDF、DOCX 文档入库与状态追踪。
3. 知识问答：结合向量检索与关键词检索生成带来源依据的回答。
4. 业务查询助手：当问题涉及实时业务状态时，可查询订单、物流、支付或退款信息。

### 3. 部署形态

- 标准版：适用于单团队快速落地，使用默认知识库配置。
- 专业版：支持多知识库运营、接入更多内部文档和流程材料。
- 私有化部署：适用于对数据隔离、网络边界和系统集成有要求的企业客户。

### 4. 数据接入范围

标准交付范围默认支持：

- PostgreSQL
- MySQL
- 企业内部 HTTP API
- TXT / Markdown / PDF / DOCX 文档

如果客户要求接入 Oracle、SQL Server、Elasticsearch 或其他异构系统，需要先由项目经理组织集成评估，确认认证方式、网络连通性、字段映射和实施周期后再进入定制交付。

### 5. 交付边界

平台默认提供知识库问答、向量索引和业务查询能力，不默认包含客户侧复杂主数据治理、跨系统流程编排或定制报表开发。

## 常见问答

### Q1：客户要求接入 Oracle / Elasticsearch 时需要走什么流程？

A：需要走定制化集成评估流程，由项目经理牵头确认数据源类型、访问方式、字段映射、同步频率、安全要求和交付排期，评估通过后再进入实施。

### Q2：平台是否只支持单一知识库？

A：不是。平台支持创建多个知识库，并在问答和文档查询时按当前知识库隔离。

### Q3：哪些团队适合优先使用该平台？

A：产品、售后、实施、运营和客户成功团队都适合优先使用，尤其适合文档多、问答频繁且需要补充业务状态查询的场景。
